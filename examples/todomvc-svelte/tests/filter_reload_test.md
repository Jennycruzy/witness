# The chosen filter stays selected after a reload

## Add two todos
Type "Buy milk" in the new todo box and press Enter, then type "Walk dog" and press Enter.

## Complete one todo
Tick the checkbox next to "Buy milk".

## Show completed todos
Click the "Completed" filter.

## Reload
Reload the page.

## Add a todo after the reload
Type "Call mom" in the new todo box and press Enter.

## Check the filter
Verify the "Completed" filter is the selected filter.
