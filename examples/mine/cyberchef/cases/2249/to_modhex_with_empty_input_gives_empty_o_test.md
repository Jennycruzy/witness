# To Modhex with empty input gives empty output instead of an error

## Add From Hex
Type "From Hex" in the Operations search box and double-click "From Hex" in the list to add it to the recipe

## Add To Modhex
Type "To Modhex" in the Operations search box and double-click "To Modhex" in the list to add it to the recipe below From Hex

## Clear the input
Click in the Input box, type "a", then press Backspace so the Input box is empty

## Check empty output
Verify the Output box is completely empty and shows no error message
