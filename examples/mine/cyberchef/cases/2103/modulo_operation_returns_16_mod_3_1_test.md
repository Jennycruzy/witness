# Modulo operation returns 16 mod 3 = 1

## Search modulo operation
Type "mod" in the Operations search box

## Add modulo to recipe
Double-click the modulo operation (Mod/Modulo/Modulus) in the Operations list to add it to the recipe

## Set divisor to 3
In the modulo recipe card, set the modulus (divisor) argument field to 3

## Enter input number
Click the Input box and type 16

## Check output
Verify the Output box shows exactly "1"
