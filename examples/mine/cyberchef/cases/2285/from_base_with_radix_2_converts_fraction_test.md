# From Base with radix 2 converts fractional input 10.1 to 2.5

## Search operation
Type "From Base" in the Operations search box

## Add From Base
Double-click the "From Base" operation in the Operations list to add it to the Recipe

## Set radix
In the From Base recipe card, clear the Radix field and type "2"

## Enter input
Click in the Input box and type "10.1"

## Check output
Verify the Output box shows exactly "2.5"
