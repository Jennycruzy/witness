# Jq operation extracts a field from JSON input

## Find Jq operation
Type "Jq" in the Operations search box

## Add Jq to recipe
Double-click the "Jq" operation in the Operations list to add it to the recipe

## Enter jq query
Type ".a" in the Query field of the Jq recipe card

## Enter JSON input
Type {"a": 1} in the Input box

## Check output
Verify the Output box shows exactly "1"
