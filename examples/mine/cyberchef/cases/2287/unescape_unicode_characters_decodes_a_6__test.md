# Unescape Unicode Characters decodes a 6-digit U+ code point

## Search for operation
Type "Unescape Unicode Characters" in the Operations search box

## Add operation to recipe
Double-click "Unescape Unicode Characters" in the Operations list to add it to the Recipe

## Choose U+ prefix
In the Unescape Unicode Characters recipe card, choose "U+" in the Prefix dropdown

## Enter escaped input
Click the Input box and type U+000041

## Check decoded output
Verify the Output box shows exactly "A"
