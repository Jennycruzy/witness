# Parse IP range reports the network address for a CIDR input

## Search for operation
Type "Parse IP range" in the Operations search box

## Add to recipe
Double-click "Parse IP range" in the Operations list to add it to the Recipe

## Enter CIDR input
Click in the Input box and type "10.1.2.3/24"

## Check network line
Verify the first line of the Output box shows "Network: 10.1.2.0"
