# Median of unsorted odd-length list returns the true median

## Find Median operation
Type "Median" in the Operations search box

## Add Median to recipe
Double-click the "Median" operation in the Operations list to add it to the recipe

## Choose comma delimiter
In the Median recipe card, choose "Comma" in the Delimiter dropdown

## Enter input numbers
Click in the Input box and type "10,1,2"

## Check median output
Verify the Output box shows exactly "2"
