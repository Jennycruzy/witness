CyberChef (GCHQ's "cyber swiss army knife" web app), served locally, freshly loaded.
Layout: left "Operations" list with a search box; middle "Recipe" area (empty at start); right "Input" box (top) and
"Output" box (bottom). To use an operation: type its name in the Operations search box, then double-click the operation
in the list to add it to the recipe; its arguments appear in the recipe card (text fields, dropdowns, checkboxes).
Typing in the Input box runs the recipe automatically ("Auto Bake" is on) and the result appears in the Output box.
