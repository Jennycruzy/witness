Actual Budget (personal budgeting web app), running locally with no server.
When the test starts: a fresh local budget is open on the Budget page (current month), with one empty on-budget
account named "Checking" (no transactions) and the default categories (Food, General, Bills, Savings, etc.).
The sidebar has Budget, Reports, Schedules, More (Payees, Rules, Settings), and the account "Checking".
In an account, "Add New" adds a transaction row with Date, Payee, Notes, Category, Payment and Deposit fields and an "Add" button.
Amounts show with two decimals and a comma thousands separator (1,200.00).
