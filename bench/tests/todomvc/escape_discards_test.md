# Escape discards an edit

## Add a todo
Type "buy milk" in the new todo box and press Enter.

## Start editing
Double-click the "buy milk" todo to edit it.

## Change the text and cancel
Replace the text in the edit box with "changed", then press Escape.

## Click the new todo box
Click the "What needs to be done?" box.

## Check the todo
Verify the todo list shows exactly one todo and its text is "buy milk".
